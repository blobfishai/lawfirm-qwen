# reports/ — failure-mode report per measured model

Generated by `node sim/build-failure-report.mjs --all` from the episode corpus: overall score,
flaky-21 boundary score, every failing episode classified into the failure-mode taxonomy
(sim/lib/classify-failure.mjs), worst practice areas/shapes, verifier-condition totals, and an
exemplar trace per mode. The audit separating model failures from harness bugs is docs/AUDIT.md.
