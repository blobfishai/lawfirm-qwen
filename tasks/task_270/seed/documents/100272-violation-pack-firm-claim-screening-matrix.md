# Violation pack — Firm claim-screening matrix

CLAIM-SCREENING MATRIX (firm standard)

Category slugs (use exactly one per identified claim):
  retaliation_whistleblower — adverse action following a protected report to a regulator, with temporal proximity.
  wage_hour_meal_break — unpaid work during statutorily required meal periods.
  discrimination_protected_class — adverse action because of a protected characteristic.
  wrongful_termination_public_policy — termination contravening a clearly mandated public policy.
  defamation — publication of a false statement of fact causing reputational harm.

Screening rule: file one evidence record per claim category SUPPORTED by the intake facts. Do NOT file a category the facts do not support — an unsupported claim category is a screening error.
