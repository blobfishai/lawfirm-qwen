# Screening pack — Firm AML policy: acceptance decision rules

AML CLIENT-ACCEPTANCE POLICY (firm standard)

Rule 1. A file may be CLEARED only when every beneficial owner holding 25% or more has been identified as a natural person AND screened with no match.

Rule 2. Where a holder of 25% or more is a corporate nominee whose natural persons have not been provided, the file must be placed on HOLD pending beneficial-ownership resolution. It must not be cleared and it must not be declined on that basis alone.

Rule 3. A file must be DECLINED where any identified party returns a sanctions match, or where the client refuses to provide beneficial-ownership information after two documented requests.

Rule 4. Enhanced due diligence applies to any file with a PEP match or a high-risk jurisdiction; EDD alone does not prevent clearance.

Decision vocabulary (use exactly): cleared | hold_beneficial_ownership | declined
