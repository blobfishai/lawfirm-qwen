# Clause library — CL-115 Clause that requires notice to terminate auto-renew

PRECEDENT CLAUSE CL-115
Category: Clause that requires notice to terminate auto-renew
Library slug: auto_renew_notice_to_terminate
Approved by: Contracts KM Committee

AUTO-RENEWAL. This Agreement shall automatically renew for successive twelve (12) month terms unless either party delivers written notice of non-renewal at least ninety (90) days before the end of the then-current Term.

Use note: this is firm-approved precedent language; deviations require playbook escalation.
