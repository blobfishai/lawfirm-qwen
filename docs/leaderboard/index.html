Methodology

Environment

The world (id sbx_206712ec47f741d3) runs fully locally: world/local/server.py hydrates the shipped world document into SQLite and serves the same session/MCP/verify surface the original hosted runtime exposed. Fidelity is proven by a reference-walk oracle: 156/156 original tasks execute and pass their shipped verifiers. Seeded friction is active: 3% injected rate_limited/stale_reference tool failures, 15% ambiguous write-acks, per-session write cap — all deterministic.

Protocol

Each episode: fresh session (pristine DB copy), the task prompt verbatim, all 102 world tools exposed via MCP, reference-relative turn budget (3× walk length + 6, min 50). Scoring calls the task's VCode verifier with the full rollout trace: structural conditions decide pass/fail; anti-hack conditions (workflow shortcuts, fabricated rows, collateral damage) veto reward to 0; tool-success is advisory. 1 task(s) quarantined from scoring for prompt/verifier drift (task_016).

Honesty notes

  • Scores are world-specific. Cross-harness comparison of absolute numbers is invalid — the same LAB family yields 26.7% (AA), ~7–12% (Harvey held-out), ~13.3% (Vals) top all-pass under three different graders.
  • All models measured on the identical scored task set.
  • Verifiers are generated and execution-grounded, not attorney-reviewed; they grade operational correctness (right records, right values, right evidence chain), not prose quality.
  • qwen3-8b is the repo's target training policy; it appears here only when an endpoint is configured (QWEN_BASE_URL).
