# Tools — inventory and research anchoring

All 102 executable tools, grouped by the MCP system that serves them
(`mcp/systems.json`, one server per firm product), with each tool's research anchoring
resolved from the world document's evidence corpus: **289 evidence items** collected by **16 live research queries** at generation time (kinds: mcp_server×4, mcp_tool×74, research_evidence×144, eval_benchmark×7, api_doc×60).

**Honesty box.** Anchoring strength varies and is stated per tool:
80/102 tools carry
resolvable anchor evidence; the rest are runtime/CRUD surfaces admitted by execution
testing only. The original generation's own scorecard flagged research-angle breadth 4/12 —
the base world's grounding is real but partial. The expansion packs' anchoring is separate
and stronger: every expansion task cites its benchmark (CUAD/MAUD/LegalBench/BigLaw/
TaxCalcBench/Stanford-HAI/court-rules) with the vendored source read at authoring time
(`data/research/legal-eval-inventory.md`), and each task's `provenance.source_workflow`
names its anchor. The sales world raises this bar further: tools mocked 1:1 from real
product APIs/MCP docs (`docs/SALES-WORLD-DESIGN.md` §2).
